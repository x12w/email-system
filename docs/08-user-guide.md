# 用户使用说明

本文档面向系统使用者和本地演示人员，说明如何启动项目、登录系统、收发邮件、查看智能分析结果，以及处理联系人和推送提醒。

## 访问地址

本地开发环境默认地址：

| 服务 | 地址 | 用途 |
| --- | --- | --- |
| 前端系统 | `http://localhost:5173/` | 登录和使用邮件系统 |
| 后端 API | `http://localhost:8080/api` | 前端调用的 REST 接口 |
| Mailpit | `http://localhost:8025` | 查看本地测试邮件 |
| MinIO 控制台 | `http://localhost:9001` | 查看对象存储服务 |

默认演示账号：

```text
用户名：admin
密码：password
```

## 启动系统

### 1. 启动依赖服务

在项目根目录执行：

```bash
docker compose up -d mysql redis minio mailpit
```

启动后可检查状态：

```bash
docker compose ps
```

### 2. 启动后端

在 `backend/` 目录执行：

```bash
mvn spring-boot:run
```

后端默认使用 `dev` 配置，服务地址为：

```text
http://localhost:8080/api
```

### 3. 启动前端

在 `frontend/` 目录执行：

```bash
npm install
npm run dev
```

前端默认地址为：

```text
http://localhost:5173/
```

## 登录与退出

1. 打开 `http://localhost:5173/`。
2. 输入默认账号 `admin` 和密码 `password`。
3. 登录成功后进入邮件工作台。
4. 左上角显示当前使用者名称，旁边的退出按钮可清理本地登录状态并返回登录页。

系统使用 `Authorization: Bearer <accessToken>` 访问后端接口。登录过期或 token 无效时，前端会自动回到登录页。

## 邮件工作台

登录后进入三栏工作台：

| 区域 | 说明 |
| --- | --- |
| 左侧栏 | 文件夹、邮箱账号、智能插件状态 |
| 中间栏 | 邮件列表、搜索、筛选、当前列表统计 |
| 右侧栏 | 邮件详情、正文、状态标签、智能分析结果 |

### 黑暗模式

左上角用户信息旁提供主题切换按钮：

- 月亮图标：切换到黑暗模式。
- 太阳图标：切换到浅色模式。

系统会将主题偏好保存在浏览器本地存储中。刷新页面或重新登录后，会继续使用上次选择的主题。

### 文件夹切换

左侧文件夹包含：

- 收件箱
- 已发送
- 草稿箱
- 垃圾邮件

点击文件夹后，中间列表会加载该文件夹下的邮件。文件夹右侧会显示邮件数量和未读数量。

### 搜索邮件

在中间栏顶部输入关键词后按回车，可按以下内容搜索：

- 发件人
- 邮件主题
- 正文摘要

清空搜索框后，列表恢复为当前文件夹下的邮件。

### 筛选邮件

当前支持以下筛选：

| 筛选项 | 可选值 |
| --- | --- |
| 阅读状态 | 全部、未读、已读 |
| 优先级 | 高优先级、普通、低优先级 |
| 风险等级 | 高风险、中风险、低风险、无风险 |

启用筛选后，筛选条件会显示为标签。点击标签上的关闭按钮可移除对应条件。

### 刷新列表

点击顶部刷新按钮会重新加载：

- 邮箱账号
- 文件夹
- 智能插件状态
- 推送事件
- 当前邮件列表

## 查看和处理邮件

### 查看邮件详情

点击中间列表中的任意邮件，右侧会显示：

- 邮件主题
- 发件人
- 收件人
- 接收时间
- 阅读状态
- 优先级标签
- 风险标签
- 邮件正文
- 智能分析结果

### 标记已读或未读

在邮件详情右上角点击眼睛图标，可切换当前邮件的已读状态。列表中的未读邮件会有蓝色标记和加粗标题。

### 删除邮件

在邮件详情右上角点击删除图标，会从当前演示数据中移除该邮件。

## 写邮件和草稿

点击左侧“写邮件”按钮打开写信抽屉。

可填写：

- 发信账号
- 收件人
- 主题
- 正文

收件人支持使用英文逗号分隔多个地址，例如：

```text
user@example.com, team@example.com
```

### 发送邮件

点击“发送”后，邮件会进入“已发送”文件夹。

### 保存草稿

点击“存草稿”后，邮件会进入“草稿箱”。

当前版本提供演示级发送闭环，后续接入真实 SMTP 后，发送动作会通过 Jakarta Mail 投递到配置的邮件服务；本地测试时可使用 Mailpit 查看邮件。

## 智能邮件分析

邮件详情区域包含“智能分析”模块。

点击“智能分析”按钮后，系统会对当前邮件进行规则分析，并返回：

| 指标 | 说明 |
| --- | --- |
| 垃圾分 | 判断邮件是否可能为垃圾邮件 |
| 优先级分 | 判断邮件是否需要优先处理 |
| 风险分 | 判断邮件是否包含可疑链接或高危内容 |
| 风险命中表 | 展示命中的 URL、风险等级和原因 |

当前演示实现使用 Java 规则插件兜底，后续可替换为 Python native 插件。插件设计详见 `docs/07-intelligent-mail-management.md`。

### 风险等级含义

| 等级 | 含义 |
| --- | --- |
| 无风险 | 未发现明显风险 |
| 低风险 | 存在轻微可疑特征 |
| 中风险 | 存在需要人工确认的风险 |
| 高风险 | 存在明显危险行为，例如可疑支付或登录链接 |
| 严重风险 | 极高危内容，生产环境应阻止自动打开链接 |

### 优先级含义

| 标签 | 含义 |
| --- | --- |
| 高优先 | 包含紧急、审批、故障、合同到期等关键内容 |
| 普通 | 无明显优先处理信号 |
| 低优先 | 低价值或弱相关邮件 |

## 联系人

右下角联系人按钮可打开联系人面板。

支持：

- 搜索联系人
- 新增联系人
- 查看联系人邮箱

新增联系人时需填写姓名和邮箱地址。联系人数据在当前演示服务中以内存方式保存，重启后会恢复为初始演示数据。

## 推送事件

右下角铃铛按钮可打开推送事件面板。

系统会展示高风险或高优先级相关提醒。点击某条推送事件后：

1. 系统将该事件标记为已读。
2. 自动打开关联邮件。
3. 可在右侧查看邮件详情和智能分析结果。

## 邮箱账号与插件状态

左侧下方展示当前邮箱账号和智能插件状态。

邮箱账号用于写邮件时选择发件身份。智能插件状态用于确认分析能力是否启用。

当前版本默认提供：

```text
admin@example.com
python-mail-intelligence / ready
```

## 常见问题

### 1. 打不开前端页面

确认前端服务已启动：

```bash
cd frontend
npm run dev
```

默认访问：

```text
http://localhost:5173/
```

### 2. 登录后接口报错

确认后端服务已启动：

```bash
cd backend
mvn spring-boot:run
```

再访问健康检查：

```text
http://localhost:8080/api/health
```

### 3. 后端无法连接数据库

确认 MySQL 容器正在运行：

```bash
docker compose ps
```

如未启动，执行：

```bash
docker compose up -d mysql redis minio mailpit
```

### 4. 修改前端后页面没有变化

确认浏览器访问的是开发服务地址 `http://localhost:5173/`，并刷新页面。Vite 会自动热更新大多数前端改动。

### 5. 数据重启后恢复初始状态

当前账号、联系人、邮件、推送事件等业务数据部分采用演示内存实现。重启后端后，会重新载入初始演示数据。后续接入完整数据库服务后，可实现持久化。

## 操作建议

初次演示建议按以下顺序体验：

1. 使用 `admin/password` 登录。
2. 在收件箱查看未读邮件。
3. 使用“风险等级”筛选高风险邮件。
4. 打开高风险邮件并点击“智能分析”。
5. 点击右下角铃铛查看推送事件。
6. 点击“写邮件”，发送一封测试邮件。
7. 切换到“已发送”查看发送结果。
8. 打开联系人面板，新增一个联系人。
