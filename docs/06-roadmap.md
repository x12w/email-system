# 开发任务拆分建议

## 第一阶段：基础框架

1. 初始化 Vite 前端项目。
2. 初始化 Spring Boot 后端项目。
3. 接入 MySQL、Redis、MyBatis-Plus。
4. 完成统一响应、统一异常、参数校验。
5. 完成 Docker Compose 本地依赖服务。

## 第二阶段：认证与权限

1. 用户表、角色表、登录审计表。
2. Spring Security + JWT 登录。
3. 前端登录页、路由守卫、Axios token 注入。
4. token 过期处理和退出登录。

## 第三阶段：邮箱账号与发信

1. 邮箱账号 CRUD。
2. SMTP 配置测试。
3. Jakarta Mail 发信。
4. Mailpit 联调。
5. 附件上传和发送。

## 第四阶段：收信与邮件管理

1. IMAP 同步邮件。
2. 文件夹同步和未读数。
3. 邮件列表、详情、搜索。
4. 标记已读、删除、草稿。

## 第五阶段：联系人与体验优化

1. 联系人 CRUD。
2. 写信页联系人自动补全。
3. 邮件列表筛选和分页优化。
4. 附件预览、下载权限校验。

## 第六阶段：智能邮件管理

1. Java 后端新增 `intelligence` 模块，完成分析任务编排。
2. Python 插件实现垃圾邮件、高优先级和恶意链接检测。
3. 定义并冻结 dll/so 插件 ABI 和 JSON 输入输出。
4. 保存智能分析结果、风险命中项和推送事件。
5. 邮件列表支持垃圾邮件、高优先级、风险等级筛选。
6. 前端展示风险标识、优先级标识和推送通知。

## 第七阶段：部署与运维

1. 前端 Dockerfile。
2. 后端 Dockerfile。
3. Nginx 静态资源和 API 代理。
4. 生产配置、日志、健康检查。
5. 数据备份策略。
6. Python 智能插件 CI 构建、签名、校验和发布。
